# Landing reference rebuild

## Outcome

Rebuild the landing page around the approved target board while preserving Reclaim's real sample data, dynamic navigation, motto behavior, and locked footer.

## Visual system

- Warm ivory environmental base with quiet, seam-safe chapter edges.
- Editorial serif display type paired with the existing sans for product UI and supporting copy.
- Charcoal product surfaces only where real evidence or workflow is shown.
- Mint only for selected records, evidence links, readiness, and recovery outcomes.
- Generated imagery is limited to static material scenes and blank physical objects. All copy, data, controls, and logos remain live HTML.

## Chapter map

1. Hero: asymmetric editorial copy over a generated archival-ledger scene; real recommended-case preview integrated at the bottom.
2. Motto: automatic handwriting reveal on arrival, no scroll lock; the principle and “That’s Reclaim.” remain in normal flow.
3. Ledger: headline on ivory, one centered dark source-ledger surface, and an attached evidence note. Sequence is rows → relationship → review candidate.
4. Evidence: real Payment A / Payment B comparison plus rule explanation; remove generic feature cards.
5. Workflow: source badges → validated import summary → extracted evidence → real Overview / Findings / Recovery workspace labels.
6. Results: truthful “Likely recoverable in this sample” metric visibly tied to selected source rows and amounts.
7. Recovery: one assembled case file using the real decision and recovery states.
8. Security: large browser boundary demonstrating local processing, persistence, and explicit deletion.
9. Pricing: light four-ticket marketing timeline; do not impersonate product state.
10. About: editorial statement with simple principle and grounded records—no rounded slogan card.
11. FAQ: calm split layout with document anchor and ruled accordion.
12. Footer: retain existing dark dither CTA/navigation and no giant moving wordmark.

## Motion choreography

- Wake: transform-only rise/settle, 250ms entry curve, 60ms stagger. No opacity-only section fades.
- Shared evidence: rules and connectors draw from left origin before dependent labels resolve.
- Product surfaces: masked inner transform reveals; no large paint-heavy clip-path animations.
- Motto: handwriting runs once on intersection and never blocks scrolling.
- Navbar: preserve normal-to-floating morph; avoid long layout-property animation.
- FAQ: short 200ms size/inner-content morph without bounce.
- Reduced motion: all content is immediately visible; functional state remains intact.

## Verification gates

- Capture and inspect 1440×900, 1280×800, and 390×844.
- No clipped words, split words, overlaps, horizontal overflow, image seams, or empty multi-screen gaps.
- Build, lint, tests, console, and network requests clean.
- Confirm below-fold scene images are lazy and non-visible chapters do not run motion work.
