Before code

Decisions for you.

  1. Payment mismatch: a piece, or an empty tile?

    What It Checks and How It Works need a fifth piece. Plan 003’s render list doesn’t have one, and plan 003 says ship an empty tile rather than a placeholder. Either add it as a 10th still (the mockups propose a green disc too big for its socket), or show check 05 with an empty pastel tile.

  2. Sub-page heroes: the shared record stack, or each page’s own piece?

    Six of the seven grey heroes reuse the landing’s record-stack film, so every first screen looks like the homepage. Security already has its own piece. If each page should get one, they are more renders for plan 003.

  3. One set of stage names

    Flagged / Proven / Approved / Requested / Settled (landing, How It Works) or Discover / Verify / Recover / Recovered / Reconcile (Pricing’s ledger).

  4. Copy to confirm

    A few short labels and lines in the mockups aren’t strings on today’s pages (lane labels on Pricing, chips on Security, two About CTAs…). The list, with what each paraphrases, is in KIT.md §17.

  5. The small grey text

    The landing’s grey (#827d73) is 3.95:1 on paper, under the 4.5:1 minimum for body text. The mockups use #6b665d (the app’s muted grey) for anything under 24px. The landing’s own captions, closer promises and summary card still use the lighter grey; one token change would fix them too.
